# libwunix

> Системная библиотека рантайма на языке Rust для пространства пользователя (Ring 3) операционной системы Wunix.

## Описание

`libwunix` — официальная базовая библиотека для разработки программ пространства пользователя в операционной системе Wunix на языке Rust.

Библиотека разработана в парадигме `no_std` с подключением динамического аллокатора `alloc` и предоставляет высокоуровневые, безопасные и идиоматичные абстракции над системными вызовами ядра Wunix (Linux/POSIX x86_64 Syscall ABI).

### Архитектура и модули

- **`syscall`** — низкоуровневые безопасные обертки ассемблерной инструкции `syscall` процессора x86_64 (`syscall0` .. `syscall6`), перечисление номеров сисколлов и валидация возвращаемых кодов.
- **`errno`** — строгая типизация кодов ошибок POSIX (`Errno`), удобная конверсия результатов системных вызовов в `Result<T, Errno>` и сопоставление текстовых описаний ошибок.
- **`fmt`** — реализация макросов форматированного вывода `print!`, `println!`, `eprint!`, `eprintln!` в стандартные дескрипторы вывода (stdout/stderr) через системный вызов `sys_write`.
- **`env`** — функции чтения, парсинга и итерирования по переменным окружения процесса (`PATH`, `USER`, `HOME`, `PWD`, `TERM`).
- **`i18n`** — подсистема интернационализации пользовательских приложений: определение системного языка из `/etc/locale` и функция выбора перевода `t("RU текст", "EN text")`.
- **`terminal`** — управление терминалом VT100/ANSI, переключение в неканонический режим (raw mode), чтение символов клавиатуры, считывание строк с редактированием и ввод паролей с маскировкой (`read_password_masked`).
- **`passwd`** — безопасный парсинг учетных записей пользователей и групп: чтение баз данных `/etc/passwd`, `/etc/shadow`, `/etc/group` и авторизационных правил `/etc/sudoers`.
- **`crypto`** — реализация криптографического хеширования SHA-256 и верификации соленых хешей паролей пользователей.
- **`time`** — конвертация меток системного таймера ядра, преобразование UNIX-эпохи в календарные дату и время, форматирование меток времени для логов.
- **`net`** — сетевой клиент BSD-сокетов: создание TCP/UDP/ICMP сокетов, разрешение доменных имен DNS через `/etc/resolv.conf`, локальный DNS-кэш, а также протоколы синхронизации сетевого времени NTP (`ntpdate`, `timesyncd`).
- **`syslib`** — акселерация через страницу vDSO (`0x00007FFFFFFF0000`): прямой доступ к меткам времени ядра и быстродействующим алгоритмам копирования памяти.

## Использование

Для создания бинарного приложения под Wunix достаточно подключить `libwunix` в зависимостях `Cargo.toml`:

```toml
[dependencies]
libwunix = { path = "../libs/libwunix" }
```

Пример минимальной утилиты на чистом Rust без стандартной библиотеки:

```rust
#![no_std]
#![no_main]

extern crate alloc;

use libwunix::{println, t};

#[no_mangle]
pub extern "C" fn _start() -> ! {
    println!("{}", t("Привет, Wunix!", "Hello, Wunix!"));
    libwunix::exit(0);
}

#[panic_handler]
fn panic(_info: &core::panic::PanicInfo) -> ! {
    libwunix::exit(1);
}
```

## Статус реализации

- **Реализовано**: обертки системных вызовов Linux ABI (VFS, управление процессами, память, сокеты, сигналы), потоковый вывод, i18n, парсинг auth-баз, sha256, сокетный сетевой стек, DNS резолвер с кэшированием, NTP клиент, интеграция с vDSO.
- **Не реализовано**: динамический компоновщик shared libraries (`.so`), асинхронный Tokio-подобный рантайм поверх `epoll` (запланирован в будущих версиях).

## Сборка

Библиотека компилируется для целевой платформы ядра Wunix:

```bash
cargo build --release --target x86_64-unknown-none
```
